Exercise: 65 (Serge I: 2009-08-24)

Number the unique pairs {maker, type} in the Product table, ordering them as follows:
- maker name in ascending order;
- type of product (type) in the order PC, Laptop, Printer.
If a manufacturer produces more than one type of product, its name should be displayed in the first row only;
other rows for THIS manufacturer should contain an empty string (').



WITH
uniq_pairs AS (
    SELECT DISTINCT maker, type FROM Product
),
ordered AS (
    SELECT
    *
    , ROW_NUMBER() OVER(PARTITION BY maker ORDER BY
        CASE WHEN type='PC' THEN 1
             WHEN type='Laptop' THEN 2
             WHEN type='Printer' THEN 3
             ELSE 4 END ASC) AS internal_num
    , ROW_NUMBER() OVER(ORDER BY maker ASC,
        CASE WHEN type='PC' THEN 1
             WHEN type='Laptop' THEN 2
             WHEN type='Printer' THEN 3
             ELSE 4 END ASC) AS num
    FROM uniq_pairs
)
SELECT 
    num
    , CASE WHEN internal_num=1 THEN maker
           ELSE '' END AS maker
    , type
FROM ordered

Among the passengers who flew with at least two airlines find those who traveled the same number of times with each of these airlines. Display the names of such passengers.

    FROM Pass_in_trip
    INNER JOIN Trip ON Trip.trip_no=Pass_in_trip.trip_no
    GROUP BY id_psg, id_comp
)
SELECT
    --psg_trips.id_psg
    Passenger.name
    --, COUNT(DISTINCT id_comp) AS companies
    --, CASE WHEN MIN(trips)=MAX(trips) THEN 1 ELSE 0 END AS same_flag
FROM psg_trips
LEFT JOIN Passenger ON Passenger.ID_psg = psg_trips.id_psg
GROUP BY psg_trips.id_psg, Passenger.name
HAVING COUNT(DISTINCT id_comp) > 1
    AND MIN(trips)=MAX(trips)



Exercise: 93 (Serge I: 2003-06-05)

For each airline that transported passengers calculate the total flight duration of its planes.
Result set: company name, duration in minutes.


WITH
durations AS (
SELECT DISTINCT
    Trip.id_comp
    , date
    , Trip.trip_no
    , time_out
    , time_in
    , CASE WHEN EXTRACT(EPOCH FROM time_in) - EXTRACT(EPOCH FROM time_out) > 0 
                 THEN time_in - time_out
               ELSE time_in - time_out + INTERVAL '24 hour' END AS duration
FROM Pass_in_trip
INNER JOIN Trip ON Trip.trip_no=Pass_in_trip.trip_no
)
SELECT
    Company.name
    , EXTRACT(EPOCH FROM SUM(duration)) / 60 AS duration
FROM durations
LEFT JOIN Company ON Company.ID_comp=durations.id_comp
GROUP BY durations.id_comp, Company.name

Exercise: 66 (Serge I: 2003-04-09)

For all days between 2003-04-01 and 2003-04-07 find the number of trips from Rostov with passengers aboard.
Result set: date, number of trips.

WITH
period AS (
SELECT 
generate_series('2003-04-01'::DATE, '2003-04-07'::DATE, '1 day') AS dt
),
trips_from_rostov AS (
SELECT
    date
    , COUNT(DISTINCT Trip.trip_no) as cnt
FROM Pass_in_trip
INNER JOIN Trip ON Trip.trip_no=Pass_in_trip.trip_no
WHERE date::DATE >= '2003-04-01' 
    AND date::DATE < '2003-04-07'::DATE + INTERVAL '1 day'
    AND town_from='Rostov'
GROUP BY date
)
SELECT
   period.dt::TIMESTAMP
   , COALESCE(cnt, 0) as cnt
FROM period
LEFT JOIN trips_from_rostov ON trips_from_rostov.date=period.dt

Exercise: 64 (Serge I (https://sql-ex.ru/users_page.php?username=Serge%20I): 2010-06-04)

Using the Income and Outcome tables, determine for each buy-back center the days when it received funds but made no payments, and vice versa.
Result set: point, date, type of operation (inc/out), sum of money per day.


SELECT 
    point,
    date,
    CASE WHEN SUM(inc) > 0 THEN 'inc' 
         ELSE 'out' END AS operation,
    COALESCE(SUM(inc), SUM(out)) AS money
FROM (
    SELECT point, date, inc, NULL AS out FROM Income
    UNION ALL
    SELECT point, date, NULL AS inc, out FROM Outcome
) AS t
GROUP BY point, date
HAVING SUM(inc) IS NULL OR SUM(out) IS NULL


Exercise: 60 (Serge I (https://sql-ex.ru/users_page.php?username=Serge%20I): 2003-02-15)

For the database with money transactions being recorded not more than once a day, calculate the cash balance of each buy-back center at the beginning of 4/15/2001.
Note: exclude centers not having any records before the specified date.
Result set: point, balance

WITH
out_payments AS (
    SELECT
        point, SUM(out) as out
    FROM Outcome_o
    WHERE date::DATE < '2001-04-15'
    GROUP BY point
),
in_payments AS (
    SELECT
        point, SUM(inc) as inc
    FROM Income_o
    WHERE date::DATE < '2001-04-15'
    GROUP BY point
) 
SELECT
    COALESCE(out_payments.point, in_payments.point)
    , COALESCE(in_payments.inc, 0) - COALESCE(out_payments.out, 0) AS remain
FROM out_payments
FULL OUTER JOIN in_payments 
    ON in_payments.point = out_payments.point

Exercise: 30 (Serge I: 2003-02-14)

Under the assumption that receipts of money (inc) and payouts (out) can be registered any number of times a day for each collection point [i.e. the code column is the primary key], display a table with one corresponding row for each operating date of each collection point.
Result set: point, date, total payout per day (out), total money intake per day (inc).
Missing values are considered to be NULL.


WITH
incs AS (
    SELECT
        point
        , date
        , SUM(inc) as inc
    FROM Income
    GROUP BY point, date
),
outs AS (
    SELECT
        point
        , date
        , SUM(out) as out
    FROM Outcome
    GROUP BY point, date
)
SELECT
    COALESCE (incs.point, outs.point) AS point
    , COALESCE (incs.date, outs.date) AS date
    , out
    , inc
FROM incs
FULL OUTER JOIN outs ON outs.point=incs.point
                     AND outs.date=incs.date

makers AS (

        , COUNT(DISTINCT type) as common_flg
    FROM Product

    HAVING COUNT(DISTINCT type)=2

Exercise: 130 (Velmont: 2015-08-14)

Historians decided to make a summary of battles and arrange it in two super columns. Each super column consists of three columns containing the battle serial number, name, and date.
First, the left super column is filled out in ascending order of serial numbers, then the right one. Serial numbers are assigned sequentially, with the battles being sorted by date, then by name.
In order to save paper the historians distribute the data from the Battles table equally between the two super columns (adding an extra battle to the left one if the total of battles is odd).
Display the result of the historians’ work as a six-column table, filling empty cells with NULL values.

WITH SortedBattles AS (
    SELECT 
        name, 
        date,
        ROW_NUMBER() OVER (ORDER BY date, name) AS rn,
        CEILING(COUNT(*) OVER () / 2.0) AS left_count
    FROM Battles
)
SELECT 
    l.rn AS num1, 
    l.name AS name1, 
    l.date AS date1,
    r.rn AS num2, 
    r.name AS name2, 
    r.date AS date2
FROM SortedBattles l
LEFT JOIN SortedBattles r 
    ON r.rn = l.rn + l.left_count
WHERE l.rn <= l.left_count;
